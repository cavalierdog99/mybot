NimbusTel support agent

A test page for an AI support assistant at a fictional Singapore and Malaysia mobile and broadband provider. It answers plan questions, verifies customers, reads bills and outage status, and hands off to a human when it should.

Open the chat with Chat with NimbusTel at the bottom right. Plan questions need no sign-in; account questions need a test account below.

NimbusTel is not a real company. Every customer, bill and outage here is invented. Don't enter real personal details.

How it works

The language model handles conversation. Anything about an account comes from an API it has to call.

  1. Chat agent on Retell AI. Holds the conversation, using a knowledge base of plans, prices and policies.
  2. Account lookups are tool calls to a small API on Cloudflare Workers holding fictional data: verification, bills, outages, tickets, number transfers and handoff to a human.
  3. The API enforces verification, not the prompt. Verifying returns a signed 15-minute token, and every account lookup requires it. If the model is talked into skipping verification, the API still refuses.
  4. Hard rules are structural where possible. The ticket API won't create duplicates; the bill API returns no figures for an unissued bill; requests it can't fulfil go to a logging tool instead of becoming promises.

Known limitations

Keep these in mind when judging a result.

  • Chat only for now. Voice in the browser is next.
  • Tickets raised during a chat aren't saved, so a later lookup won't show them.
  • Handoffs to a human are logged, but nobody picks them up.
  • English only. It understands some Singlish but doesn't switch language.
  • Under sustained pressure it can still occasionally phrase something too loosely. The test cases above are the ones it was tested against.
